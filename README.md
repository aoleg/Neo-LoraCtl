# Neo-LoraCtl

Fine-grained LoRA control for Stable Diffusion WebUI Forge Neo: decide **where** (which model blocks) and **when** (which sampling steps) each LoRA applies — with simple presets, not number grids.

Built for Krea 2 first, where character LoRAs often drag in unwanted style and style LoRAs distort characters. Pick a block preset (COMPOSITION / CHARACTER / STYLE), a timestep preset (COMPOSITION / CHARACTER / DETAIL), choose to emphasize or suppress, and set how strongly — that's the whole interface.

**Status: in development — not yet usable.** See [docs/PLAN.md](docs/PLAN.md) for the development plan.
